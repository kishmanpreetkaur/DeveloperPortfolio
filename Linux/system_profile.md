## 2. Binary Number Representation

### A. Convert decimal 75 into binary

Repeated division by 2:

| Division | Quotient | Remainder |
|---|---:|---:|
| 75 / 2 | 37 | 1 |
| 37 / 2 | 18 | 1 |
| 18 / 2 | 9 | 0 |
| 9 / 2 | 4 | 1 |
| 4 / 2 | 2 | 0 |
| 2 / 2 | 1 | 0 |
| 1 / 2 | 0 | 1 |

Reading the remainders from bottom to top:

**75 (decimal) = 1001011 (binary)**

### B. Convert binary 110101 into decimal

Using positional weights:

110101 = (1 x 2^5) + (1 x 2^4) + (0 x 2^3) + (1 x 2^2) + (0 x 2^1) + (1 x 2^0)

= 32 + 16 + 0 + 4 + 0 + 1

**110101 (binary) = 53 (decimal)**

### C. Why do computers use binary?

Computers use binary because their electronic circuits can reliably represent two states, ON (1) and OFF (0), making data processing and storage dependable.
